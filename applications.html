신청 준비 보드

공고를 찾은 다음, 무엇을 언제까지 준비하고, 어떤 요구에 어떤 자료와 사업계획 문안을 연결할지 정리합니다.

현재 브라우저 메모리에서만 처리
기업 조건 검토첨부 원문예비·초기 준비사업 조합·비용 배분
자동 저장·서버 전송·실제 신청은 하지 않습니다.

새로고침하면 입력이 사라집니다. 계속 작업하려면 준비 파일 저장 후 다음 접속에서 직접 불러오십시오. 이 파일은 암호화되지 않은 비공개 JSON입니다. 실명·사업자번호·계좌·서류 원본·민감한 내용은 입력하지 마십시오. GitHub 공개 저장소에 올리지 마십시오.

검증된 파일의 입력만 가져옵니다. P0.12(v1)·P0.13(v2) 파일은 작업·자료 연결을 보존하고 빈 초안 항목을 추가합니다. 새 v3 파일은 이전 화면에서 열 수 없습니다. 저장된 상태는 자체기록이며 공고의 적격성·제출·선정을 증명하지 않습니다. 현재 보드를 대체하므로 필요한 입력을 먼저 저장하십시오.

공개 공고를 읽고 있습니다.

기관에서 발견한 후보도 준비하기

중기부·NIPA 후보를 이 화면에서만 연결합니다. 원문·첨부 확인 수준은 그대로 유지되며 검증 공고로 등록하거나 자격을 승인하지 않습니다. 운영기관·입찰·정책·공모전·결과 발표는 제외하고, 사업연도가 불명확한 후보는 연결을 보류합니다.

버튼을 누르면 공개 목록과 근거 JSON 두 개만 읽습니다. 준비 입력은 보내지 않습니다.

1. 준비할 공고 담기

최대 12개. 운영기관 모집·예산안은 제외합니다. 이전 연도 참고 경로는 미래 준비용이며 실제 신청 공고가 아닙니다.

2. 오늘의 준비 현황

완료 건수는 내부 작업 진척입니다. 공식 필수서류 완비·신청 적격성·선정 확률이 아닙니다. 제출·선정 상태도 사용자가 입력한 기록입니다.

준비할 공고를 담거나 이전 준비 파일을 불러오십시오.

일정 파일의 범위

직접 입력한 작업일과 내부 목표일은 종일 일정으로 저장합니다. 기재 마감은 현재 공고 목록과 저장 정보가 일치하고 수집 상태가 최신 성공인 경우만 포함합니다. 후보·이전 연도 참고·변경·경과 마감은 공식 마감 일정에서 제외합니다. 날짜만 확인된 마감은 ‘시각 미확인’ 종일 일정이며 자정 마감으로 바꾸지 않습니다.

이 파일은 자동 갱신·알림 서비스가 아닙니다. 공고가 바뀌면 다시 확인해야 합니다. 캘린더 서비스로 가져오면 그 서비스에 내용이 저장될 수 있습니다. 중복 가져오기 처리도 사용하는 캘린더에 따라 다릅니다.
