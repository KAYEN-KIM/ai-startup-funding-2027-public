# P0.22 — 양식 버전 변경 대조·초안 재검토 게이트

## 목적

P0.21의 "로컬 양식 제목 후보" JSON을 이전/현재 두 개로 받아 변경을 대조한다.
원본이 새 버전으로 바뀌었어도 현재 브라우저가 임의로 적격성, 제출서류,
지원액, 양식 완비를 확정하지 않도록 한다. **정기 자동 운영과 AI API 호출은 없음.**

## 비교 항목 / 상태

- 원본 바이너리 SHA-256: 다르면 후보 제목이 똑같아도 원문 재검토 필요.
- 동일 SHA-256인데 제목·원문 위치/사유가 달라지면 **metadata conflict**.
  이는 생성기 버전 차이나 추출 오류일 수 있으므로 해당 결과의
  "초안 보류 해제"를 허용하지 않는다. 원본을 재추출해 문제를 해결해야 한다.
- 사용자 기재 공고 URL: 둘 다 동일해야 "같은 출처로 기재" 상태.
  실제 공공기관의 진위나 법적 동일성을 인증하지는 않는다.
- PDF/HWP/HWPX 간 포맷 차이: 명시적 재대조 대상.
- 제목 번호 표기 변경·순서 이동·인쇄 위치 추정 변화·신규/미발견 후보:
  항목별 참고 표시. "미발견"은 공식 삭제 확정이 아니다.
- 동일 제목이 여러 번 등장하면 **ambiguous_duplicate**:
  동일 제목끼리 자동 1:1 대응시키지 않는다.
- 부분 추출/40개 한도/후보가 0개인 결과: "변경 없음"이라고 결론내지 않는다.

비교 로직은 숫자·표제의 정규화와 추출된 상대 위치만 사용한다.
의미가 비슷한 두 제목을 AI나 fuzzy-matching으로 동일하다고
결론 내리지 않는다. 본문·표·첨부·서명·예외조항은 여전히 비검증이다.

## 실제 화면

[form-mapping.html](../form-mapping.html)의 "2B. 이전·현재 양식 파일의
목차 후보 변경 대조" 영역에서 P0.21 JSON 두 개를 선택한다.
브라우저만 파일을 읽는다.

1. 이전 JSON, 현재 JSON 선택. 어느 쪽이든 변경되면 기존 작업
   패킷 미리보기/내보내기를 **보류**한다.
2. 변경 후보 대조. 파일 지문과 항목별 차이, 경고를 표시한다.
3. 필요한 경우 변경 검토표 TXT를 **명시적 로컬 저장**한다.
4. 최신 공고 원문과 해당 양식의 페이지·표를 직접 비교한다.
5. 새 양식 목차를 직접 수정하거나 2A에서 후보를 복사하고,
   **목차를 다시 분석한 뒤** 초안 항목별 대응을 새로 설정한다.
6. 비교 후 재분석·수동 점검 사실을 확인 체크한 후
   "수동 재대조 기록 · 초안 출력 보류 해제" 버튼을 누른다.
7. TXT 작업 패킷을 새로 미리보기/저장한다. 이것도 공식 제출본이 아니다.

기존 v1·v2·v3 준비파일, 사용자가 작성한 문안, 공고 등록,
공개 기업 데이터 및 각종 조건 검증 규칙은 변경하지 않는다.
비교 결과는 현재 브라우저 메모리에서만 유지하며
자동 저장/서버 전송/공식 접수는 하지 않는다.

## 안전 경계

- 두 입력은 P0.21의 local-form-outline-candidates/v1 스키마,
  문서 SHA-256, candidate_unverified 상태, 파일 크기 등 검사를 통과해야 한다.
- 출처·파일표기·위치의 제어문자 삽입은 거부한다.
- 악성 제목은 HTML escaping; TXT 내보내기는 클릭했을 때만.
- 페이지의 CSP connect-src none, form-action none 유지.
- 기존 P0.20 일반 목차 대응 작업은 비교를 사용하지 않는 경우 그대로 수행한다.
- 비교 입력을 바꿨다면 가장 최근 미리보기와 내보내기는 사용 불가.
- 동일 SHA-256과 상충 목록이면 사용자 자체 확인으로도
  잠금을 해제하지 않으며 다시 파일을 추출해야 한다.
- 비교가 성공하고 사용자가 확인해도 공식기관 승인·제출자격·지원확정이 아니다.

## 시험

    node --test scripts/test_form_version.cjs
    node --check assets/form-version.js
    python scripts/build_public.py

P0.22 테스트는 GitHub Actions verify 단계에 추가되어
기존 모든 테스트와 함께 실행된다. 공개 빌드에는
assets/form-version.js만 추가하며 JSON 파일/문서 원본은 포함하지 않는다.
