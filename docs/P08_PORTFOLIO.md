# P0.8 — 사업 조합·기간·비용 배분 검토

기준 부모: `e659c5275b0993d664b81e48a4b83ed1acce1c7a` (P0.7 운영 데이터 포함).

## 목적과 범위

`portfolio.html`은 한 회사의 사업 1~3개와 유일한 비용 1~60건을 검토한다.
P0.7의 독립 대안 화면은 그대로 유지하며, 새 화면만 조건부 합산 모형을 제공한다.
새 법규, 2027 확정 한도, 신청자격, 선정 확률 또는 최적 조합을 만들지 않는다.

- 기존 참고 경로 3개·지역/단계 9개는 `CashflowCore.financeEstimate`를 통해
  `StartupCore.gate`와 기존 사업비 산식을 그대로 사용한다.
- 원본 SHA·프로그램 스냅샷·참고연도·7일 내 성공 재확인에 실패하면 계산/저장을 보류한다.
- 직접 입력 사업의 유형·요청액·현금 자부담·현물은 사용자 가정이다. 별도 공고 규칙이 아니다.
- 검토 연도 2026/2027, 신청/수행 구분, 수행기간, 비용 발생기간과 지급월을 각각 입력한다.
- 수행기간 겹침은 사실관계 표시일 뿐 그 자체로 위반 판정이 아니다. 비겹침도 허용 판정이 아니다.
- 예비/초기 참고 경로 둘 이상, 또는 같은 경로의 지역 대안을 함께 넣으면 합산을 차단한다.
  2026 조항의 참고 결과를 표시할 수 있지만 2027 금지 규정을 새로 만들었다는 뜻이 아니다.
  이는 미검증 대안 한도를 합산하지 않기 위한 제품 안전장치다.
- 나머지 사업 쌍은 상호 병행 조항 미검증으로 남긴다. 모든 결과의 permission은 not_determined다.

## 비용 명세의 의미

한 경제적 비용(청구·지출 단위)을 익명 비용 ID 하나와 행 하나로 기록한다.
사업별 배분액의 합은 비용 원금을 초과할 수 없다. 각 사업에 배분한 현금 합계는
그 사업의 지원액 가정 + 현금 자부담과 같아야 한다. 현물은 배분 현금이 아니다.
미배분액은 회사 단독 지출이며 전체 지출에서 한 번만 계산한다.

중복 ID, 잘못된 날짜/금액, 알 수 없는 사업 참조는 입력 오류다. 과다 배분,
사업별 예산 불일치, 수행기간 밖 발생 비용, 비인정으로 표시한 비용의 사업 배분은
충돌이다. 비용 인정 미확인은 보류다. 이 경우 합산 현금흐름은 제공하지 않는다.
사용자가 '인정 가능 가정'을 선택해도 공식 인정으로 승격하지 않는다.
지급월이 수행기간 밖인 경우는 선지급·후정산 검토 항목이지 자동 불법 판정이 아니다.

같은 비용을 다른 ID로 입력한 경우, 실제 증빙 진위, 근로시간·참여율 상한,
기존 신청/수혜 이력, 실제 적격 비용·같은 목적/산출물 여부는 자동 검증하지 못한다.
회사 운영비와 비용 명세에 같은 지출을 넣지 않는다는 확인도 사용자 가정이다.

## 조건부 합산 현금 모형

충돌/보류가 없는 비용 명세에 한해서만 지원금 없음, 전부 선정·병행 가정,
전부 선정·지급 지연 가정을 비교한다. 이 계산 가능 상태는 조합 허용이 아니다.
지원사업별 사용 가능한 지원금은 P0.7과 같은 **분석 모델의 가정**을 쓴다.

사업 i: 지원액 G_i, 현금 사업비 C_i, 누적 배분 현금 지출 X_i, 누적 수령 R_i.
누적 환입 U_i = min(R_i, floor(X_i * G_i / C_i)).
사업별 제한 지원금 = R_i - U_i. 서로 다른 사업의 미사용 지원금을 합쳐 다른 사업의
비용 인정이나 자부담으로 배분하지 않는다. 현물은 현금이 아니다.

회사 가용 현금 = 이전 가용 현금 + 매출 입금 + 투자 + 차입 + 당월 환입 합계
- 공통 운영비 - 유일 비용 원금 합계 - 별도 추가지출 - 원금상환 - 이자.
공통 운영비와 공유 비용의 원금은 회사 전체에서 한 번만 차감한다.
전체 현금 = 가용 현금 + 사업별 제한 지원금 합계.

실제 환입·전용계좌 이동·비용 인정·교부·정산 규칙이 아니며 사업별 협약 확인이 필요하다.
자부담은 사업비에 포함되어 있으므로 다시 지출로 더하지 않는다. 보증·세액공제는
현금 유입으로 받지 않는다. 기초 차입원금은 기초 현금에 더하지 않는다.
원금상환은 누적 차입원금을 넘을 수 없다. 월중 결제 순서·세금·부가세·삭감·환수는 미구현이다.

## 입력과 개인정보 보호

공개 JSON 3개만 초기 로드 또는 명시적 다시 읽기에서 GET한다.
입력의 자동 저장·네트워크 전송·로그·쿠키·로컬스토리지·분석 서비스가 없다.
실명·사업자번호·실제 증빙번호 없이 P1/C1 같은 익명 토큰으로 검토한다.
명시적 버튼만 private-portfolio-plan-export/v1 JSON 또는 기관 질문 TXT를 로컬 저장한다.
입력 변경은 결과/저장을 무효화하며, 이벤트 없는 값 변경도 저장 직전 대조한다.
저장 직전 근거 상태·나이를 다시 검사한다. 근거가 보류되면 이전 결과를 내보내지 않는다.
유효한 충돌 보고서는 저장 가능하되 시나리오는 null이며 충돌과 미확정 상태를 포함한다.

## 시험

```
node --test scripts/test_portfolio.cjs scripts/test_portfolio_ui.cjs
python -m unittest discover -s scripts -p test_portfolio_contract.py -v
```

산식 시험은 단일 사업 결과의 P0.7 일치, 비용 원금·배분 합계, 월별 현금 보존,
사업별 제한자금, 날짜/한도/원 단위·차입 상환·지연 지급·자료 변경을 포함한다.
VM/DOM 시험은 입력·추가/삭제·결과 무효화·저장·비공개 입력 미전송을 검사한다.
실제 브라우저 시각 검수 여부는 별도 검증기록에만 기록한다.

## 남은 범위

2027 원공고의 상호 중복지원 조항, 공식 비용 인정표, 예외 승인, 동일 목적·결과물,
실제 인건비 참여율/근로시간, 지급·정산 방식, 확정 조합 최적화, 비공개 장기 저장과
공동 신청관리는 미구현이다. 계산 가능하다는 이유로 법적 적격성을 추정하지 않는다.
