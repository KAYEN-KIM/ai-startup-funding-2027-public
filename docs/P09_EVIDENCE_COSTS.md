# P0.9 — 원문 제한·비용 증빙·월 급여 원금 대조

## 범위
기존 `portfolio.html`을 확장한다. 새 서비스·로그인·개인정보 저장소·유료 호출은 없다.
공고 2개의 검토된 2026 원문 제한을 기존 기간·비용 검토에 연결한다.
공식 2027 자격·비용 인정·병행 허용·최적 조합 판정은 여전히 미구현이다.

## 검토된 근거
2026-10-29 두 원본 HWPX를 중기부 공식 첨부 URL에서 다시 내려받아 기존 등록 SHA-256과 일치함을 확인했다.
`assets/portfolio-evidence.js`의 SOURCES는 이 URL·지문·문단/표 위치에 고정되어 있다.

- 일반형: e34bdaf1618c03d37e48c4aa0836f9e03aa7b3d8b3f2b9c8a14af098a163341f
- 딥테크: 6bdb1a0a28bc4903361b8525c0e8988e7bfdd45d4f014cc55b4e49cbe409e658
- 두 문서의 표1: 초기창업 3개 유형의 신청과 수행 구분.
- 신청 제외 ⑦ 및 주석: 같은 사업연도 중앙정부·공공기관 창업사업화와 이전연도·지자체 신청 예외의 범위.
- 최종 선정자의 확약서 안내와 신청 유의사항: 최초 확약서 제출과 다른 사업 선정절차의 관계.
- 붙임5: 38개 사업명에 대한 제한목록 대응. 일반형 표47 다음 목록, 딥테크 표44 다음 목록(0부터 번호).
- 현물 안내: 대표자·직접 참여 고용인력 인건비 등이 현물 부담 예시라는 사실만 연결. 대표자 급여의 현금 지급 승인으로 해석하지 않는다.

이것은 두 원공고에서 바라본 단방향 제한이다. 반대 사업 원문 전체, 후속 개정, 회사별 예외·사실관계는 미검증이다. 목록의 각 사업을 신규 확보 가능한 지원금으로 만들지 않는다.
프로그램 이름 선택은 사용자 대응이며 실제 공고·협약을 자동 식별한 것이 아니다.
`TIPS R&D`와 `TIPS 창업사업화`는 별도 선택이며 후자를 전자의 일반 금지규정으로 확장하지 않는다.

## 규칙 적용
사업마다 공고의 사업연도와 진행상태를 별도로 입력한다. 수행기간의 연도에서 사업연도를 추정하지 않는다.
2026 검토와 2026 사업연도, 검토한 목록 대상이라는 입력이 갖춰질 때만 제한을 적용한다.
수행 계획 또는 상대의 확약·수행 상태는 제한 검토 충돌로 처리하고 합산 가정 계산을 중단한다.
신청 계획 단계에서도 목록 대상의 전부 수행을 가정하지 못하도록 보류한다. 이는 신청 자체를 무조건 금지하는 뜻이 아니다.
미확인·종료 이력은 관련 증빙을 확인해야 한다. 2027 이후는 과거 제한을 미래 확정 금지/허용으로 전환하지 않는다.
다른 연도·지자체·R&D 및 목록 밖 사업에도 최종 permission은 not_determined이다.
기존 P0.8의 예비·초기 대안 합산 차단과 원본 재확인 gate는 유지한다.
검토 원본의 SHA가 변경되면 새 원문 재검토 전 계산·내보내기를 막는다.

## 비용 증빙
같은 경제적 청구 원금에 같은 익명 코드를 지정하면 서로 다른 비용 ID 행에서도 중복을 표시한다.
실제 사업자·증빙번호·실명은 입력하지 않는다. 입력한 코드가 다르면 동일 경제적 비용임을 알아내는 기능은 없다.
증빙 미확인/준비예정/보유 상태는 사용자 기록일 뿐이다. 보유를 선택해도 실제 문서를 읽거나 비용 인정을 승인하지 않는다.
비용 종류별 계약·검수·청구기간·지급증빙 등의 제안은 내부 준비 체크리스트이며 공식 필수서류 목록이 아니다.

## 월별 인건비 산술
현금 급여 비용만 대상으로 익명 인력 코드 + 급여 대상월을 묶는다.
같은 묶음의 월 급여 원금과 다른 사업 청구액은 일치해야 한다.
여러 행의 현금 급여 원금 합계가 월 급여 원금을 초과하거나, 현재 사업 배분액+다른 사업 청구액이 월 급여 원금을 초과하면 합산 계산을 차단한다.
다른 사업 청구액은 같은 묶음에서 한 번만 합산한다. 여러 달 급여는 발생월별로 나눠야 하며 지급월 지연은 별개이다.
급여 원금 대비 청구 비율은 정확한 정수 산술 후 표시용으로 내림한다. 국가R&D 인건비계상률·연구수당·기관특례·현물·실제 업무시간을 판정하는 규칙은 아니다.
현물은 기존대로 현금흐름에 합산하지 않는다. 세금·원천징수·4대보험·일반 임금 적법성은 별도 검토한다.

## 보안과 보존
입력은 페이지 메모리만 사용한다. 자동 저장·서버전송·쿠키·브라우저 영구 저장·업로드·제출 기능이 없다.
공개 JSON 3개만 GET으로 읽는다. 명시적인 버튼으로만 비공개 JSON 또는 금액 없는 기관 질문 TXT를 로컬에 저장한다.
입력 변경/재조회/원본 확인 만료 시 이전 결과와 저장 권한을 무효화한다.
기존 data/config 원본, 다른 7개 기능의 산식, 비공개 워크스페이스, 매일 08:00 예약은 유지한다.
