공식 양식 항목 대응 작업대

공고별 작성 양식의 목차만 수동으로 옮겨 적어, 기존 사업계획서 8개 항목과 연결하고 작성용 패킷을 만듭니다.

신청 준비 보드제출 전 로컬 점검공고 현황판
공식 양식 자동 판독·기입·제출 도구가 아닙니다.

공식 공고 원문에서 확인한 항목 제목을 직접 입력합니다. 자동 추천은 제목 키워드만 비교하는 참고 자료이며, 직접 선택하기 전까지 대응은 미설정입니다. 이 화면은 서버에 자료를 전송하지 않고 저장하지 않습니다. 실명·연락처·계좌·신청서 원본을 입력하지 마십시오.

준비파일을 선택한 뒤 공식 양식의 목차를 한 줄씩 입력하십시오.

1. 기존 준비파일에서 사업계획서 불러오기

v1·v2·v3 저장파일을 지원합니다. v1·v2는 비어 있는 8개 초안 항목으로 변환됩니다. 파일은 현재 브라우저에서만 읽습니다.

2. 실제 공고의 양식 출처와 목차 입력

제목 목록만 붙여넣으십시오. 본문·개인정보는 필요하지 않습니다. 최대 40줄·12,000자입니다.

3. 양식 항목별 수동 대응

목차를 입력한 뒤 분석 버튼을 누르십시오.

4. 제출용이 아닌 작업 패킷 확인

관찰·실적, 향후 계획, 원본 근거 코드 등을 선택한 양식 항목 순서로 출력합니다. 실제 공식 양식의 표·글자수·첨부·서명 요구는 검증하지 않습니다.

아직 작성 패킷을 생성하지 않았습니다.
