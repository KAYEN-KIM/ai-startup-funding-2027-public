공개판 운영 정책

수혜기업 공고, 운영기관 모집, 예산안을 분리합니다. 직접 확인되지 않은 신청자격·금액은 추정하지 않습니다. 원본 비공개 현황판의 개인정보, 회사정보, 서류와 자금계획은 공개판으로 복제하지 않습니다.

자동수집 원천: 기업마당 지원사업정보 공식 API ↗. 정기 자동수집은 공식 API 키 등록 후 동작하며, 공고 상세의 자격·금액은 원문으로 재검증해야 합니다.
